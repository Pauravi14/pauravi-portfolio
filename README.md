# Pauravi Pardeshi — Portfolio

Personal portfolio site based on my CV: experience, projects, skills, and a bit about me.

## Open locally

Open `index.html` in your browser, or from this folder run:

```bash
npx --yes serve .
```

Then visit the local URL shown in the terminal.

## Contents

- `index.html` — page structure
- `css/styles.css` — design
- `js/main.js` — navigation + motion
- `assets/pauravi.png` — profile photo
