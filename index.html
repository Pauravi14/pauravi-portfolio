Unity · Meta Quest · Security

ADA-VR Sandbox Game

University research software — adaptive authentication in VR

Self-contained Unity VR sandbox for the ADA-VR framework at Paderborn: three authenticators on Quest (QR-Quest, randomized PIN, Head Reverberated), plus Bluetooth/context sensing and the MAPE-K analyzer–planner–executor loop. Packages are vendored so the repo clones and opens cleanly.

  • Unity 6000.3, Meta XR / OpenXR, XR Interaction Toolkit
  • Integrated Head Rev team APK workflow and Quest UI bootstrap
  • Mirror of active development branch whole-sandbox-project
Stack
C#, Unity 6, Meta Quest (Android), OpenXR, custom ADA-VR packages
Signals
Immersive UX, security engineering, large multi-package Unity architecture

Next.js · TypeScript · Live demo

AI VR Security Assistant

Public portfolio slice of ADA-VR ideas

Interactive demo of context-based risk scoring for long-lived VR sessions: change inputs (Bluetooth phone trust, network type, login time, minutes since auth) and watch risk level, human-readable explanation, and recommended action update instantly — not a black box.

  • Threshold model: Low → Critical with mapped security actions
  • Recruiter-friendly explanation of adaptive authentication
  • Independent from private university code; safe to share
Stack
Next.js (App Router), React, TypeScript, Tailwind CSS
